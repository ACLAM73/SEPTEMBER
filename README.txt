TRAMA BIRTHDAY WEBSITE
========================

Files:
- index.html     -> Home page
- memories.html  -> Photo gallery
- letter.html    -> Romantic birthday letter
- style.css      -> Styling
- script.js      -> Hearts/surprise effects
- images/        -> Uploaded photos

To test:
Open index.html in a browser.

To share as a public link:
Upload the whole folder to a static hosting service such as GitHub Pages or Netlify.
Make sure index.html stays in the main/root folder.

Note:
The website uses the photos supplied in the chat. Add more couple photos to images/ and duplicate a <figure> block in memories.html if you want a larger gallery.
